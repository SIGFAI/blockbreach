# Changelog

## 1.0.0 — first release
- Minecraft Java composited into Ready or Not (DirectX 11): depth-correct, under the HUD, lighting and haze matched,
  re-projected to Ready or Not's newest camera.
- Ready or Not's floors, stairs and walls as invisible barriers in Minecraft (multi-storey probing, walls between
  cells, doorways opened where people walk); each map gets its own region of the Minecraft world.
- Build mode (NumPad 0) with the hotbar and Minecraft's creative inventory (E); placed blocks are solid in Ready or Not.
- Cross-game combat: arrows, sword, TNT, creepers, crossbow fireworks hurt Ready or Not's people; the player's guns kill
  Minecraft's mobs (headshots ×3); suspects and the SWAT squad shoot mobs (never through the player); mobs hunt
  suspects, officers and the player.
- Stability: ReShade effects off outside the game (no crash on graphics-settings changes), no Minecraft server stalls on
  map changes, mission restarts keep the ground, crash breadcrumbs + session history log.
- BlockBreach installer/launcher: finds both games, installs/repairs/uninstalls with backups, Minecraft Launcher profile,
  dedicated-GPU preference, shortcuts, Apps & features entry, settings page, EN/RU.
